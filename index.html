§ About this project

What is GeoChat?

GeoChat is an AI assistant grounded in my Master's thesis at KIT - Impact of climate change on the geothermal potential of closed systems using GIS and Python. Rather than guessing or giving generic answers, it has the thesis context built in and responds with what the research actually says: methodology, scenarios, results, and what the numbers mean.

§ How it works

From your question to a grounded answer.

A four-step pipeline that keeps responses anchored to the thesis, not Wikipedia.

→ 01 / INPUT

You ask a question

Type any question about the thesis. Pre-filled suggestions help you get started.

→ 02 / CONTEXT

Thesis context injected

A Vercel serverless function attaches the thesis content (methodology, findings, scenarios) to the prompt.

→ 03 / AI

Gemini generates

Google Gemini reads the context and writes an answer grounded in the real research.

→ 04 / OUTPUT

Answer in your browser

The response comes back and renders in the chat thread for you to read.

§ Tech stack

Built on free, modern tools.

Vanilla web stack plus serverless AI. Zero cost to run, easy to maintain.

Frontend

Vanilla HTML / CSS / JavaScript. No framework, no build step. Sticky portfolio nav included.

Backend

Vercel serverless functions (Node.js) handle the API endpoint and prompt construction.

AI

Google Gemini with thesis context injection, free tier (1,500 requests / day).

Hosting

Vercel free tier with GitHub auto-deploy. Total infrastructure cost: €0 / month.

Development

AI-pair-programming with Anthropic Claude, ChatGPT, and GitHub Copilot. Architecture and review by me.

§ How this was built

An AI assistant, built with AI as a pair-programmer.

There's a meta layer here worth being honest about: I used AI to build an AI. Anthropic Claude was my primary pair-programmer for the Vercel serverless function, the prompt engineering strategy, the chat UI, and the embed mode. ChatGPT helped iterate on what content goes into the thesis system prompt. GitHub Copilot handled inline suggestions. I designed the architecture (prompt injection over RAG, last-6-turns conversation history, model parameters), wrote the system-prompt content rules, reviewed every line, and own the deployed system. AI accelerated the writing; the thinking and the decisions stayed mine. AI-pair-programming fluency is part of the stack I bring to my next role.
